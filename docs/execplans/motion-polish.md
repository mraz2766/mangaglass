# ExecPlan：动效打磨（丝滑切换、点击反馈、下载动效、完成彩蛋）

## 摘要

用户要求整体优化动画：切换侧栏时漫画封面突兀、点击/下载动效不够、加下载完成小彩蛋，并鼓励多想一些可加的动效。只改界面动效，不改业务逻辑；所有新增动效都遵循「减弱动态效果」设置。

## 问题根因

- 封面突兀：切页时页面重建，`CachedCoverImage` 总是先以 `.loading`（占位字）出现，下一拍才从内存缓存换成图片，所以即使已缓存也会闪一下。
- 切页过渡：两页在 `ZStack` 里同时淡入淡出 0.24s，内容叠在一起，显得糊。

## 改动

| # | 场景 | 动效 |
|---|---|---|
| 1 | 封面 | 构建时同步读内存缓存，已缓存直接显示无闪烁；只有真正从网络加载时才淡入 |
| 2 | 切页 | 旧页快速淡出（0.12s），新页弹簧上浮淡入；侧栏选中底色在图标间滑动，选中图标轻弹 |
| 3 | 分类胶囊 | 选中底色在胶囊之间滑动 |
| 4 | 分组展开 | 弹簧展开，格子依次浮现；箭头弹簧旋转 |
| 5 | 章节格 | 新下载完成的绿点弹出；选中勾弹出（已有） |
| 6 | 进度条 | 下载进行中时进度条上有一道柔和高光扫过 |
| 7 | 完成彩蛋 | 整个队列无失败完成时，窗口撒一阵彩纸；侧栏「下载」图标短暂变成绿色对勾 |
| 8 | 解析 | 解析失败时链接框左右轻晃；解析成功封面轻微放大落位 |
| 9 | 刷新 | 刷新中箭头图标持续旋转 |
| 10 | 主题切换 | 切换主题/强调色时整窗交叉淡化，不再硬切 |

## 约束

- 大幅度修改（显著交互改版）：`1.17.1` → `1.18.0`。
- 性能：彩纸用 `Canvas` + `TimelineView` 一次性绘制，约 2 秒后移除；高光只在进行中的进度条上运行；网格格子不加持续动画。
- 「减弱动态效果」开启时：无彩纸、无高光、无位移，只保留淡入淡出。

## 决策记录

- 封面：`CachedCoverImage` 在 `init` 里同步读内存缓存作为初始状态；`.task` 命中同一张图时不再重设，避免二次过渡。
- 切页：根部动画改为 `MGMotion.page`（弹簧 0.42/0.88）；插入 = 淡入 + 上移 12pt + 0.985 缩放，移除 = 0.12s 淡出。
- 侧栏：选中底色用 `matchedGeometryEffect` 在按钮间滑动；按钮改用 `MGPressScaleStyle`（按下缩到 0.9）；新选中的图标弹一下。
- 分类胶囊：只有「全部」或单个分类选中时共享滑动底色；多选时各自填充，避免多个源冲突。
- 分组展开：`withAnimation(MGMotion.page)` 包住折叠状态变化，展开前 `MGRevealClock.mark()` 让格子依次浮现；浮现序号改为组内序号（原来按「组序号×12」，越靠下的分组等待越久，最多约 0.6 秒）。
- 「刷新」按钮在加载时会被状态行替换，所以旋转放在「正在解析」状态行的图标上（`MGSpinningIcon`），而不是按钮本身。
- 彩蛋：`DownloadCoordinator.celebrationTick` 在批次无失败完成且有已完成章节时 +1；`MGCelebrationLayer` 独立观察下载器（不让整个 ContentView 跟着进度刷新），`Canvas` 画约 90 片翻转彩纸，2.4 秒后移除；侧栏「下载」图标变绿色对勾 2.8 秒。
- 主题切换：`.id` 重建无法可靠交叉淡化（主题色是全局静态值，旧视图也会用新颜色重绘），改为在属性 `willSet` 时给可见窗口截图、盖在内容视图上再淡出（`MGWindowCrossfade`）；挂在 `contentView` 而非私有的窗口框架视图上。
- 「减弱动态效果」：无彩纸、无高光、无位移/弹跳、不交叉淡化，只保留短淡入淡出。

## 结果

- 版本 `1.18.0`；`swift test` 89 项通过（4 项按设计跳过，其中 1 项为彩纸截图渲染）。
- 真实运行：切页时封面不再闪；分组展开时格子依次浮现；首页 / 下载 / 书架切换正常。彩纸用离屏渲染确认绘制效果（需一批下载全部成功才会在真实使用中出现）。
- 侧栏真实鼠标点击未在本轮复测（屏幕上 Alcove 的窗口挡住了测试点，改用辅助功能点击）；侧栏结构与 1.15.2 已验证版本相同，仅多了按下缩放。
