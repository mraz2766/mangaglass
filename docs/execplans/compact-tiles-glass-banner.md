# ExecPlan：章节格缩小、分组默认折叠、横幅改白色玻璃

## 摘要

用户反馈（截图：七大罪 · 漫画柜）：章节/卷格子太大；分组默认应折叠；漫画名下的统计胶囊（单行本 41、番外篇 30……）没有意义；封面横幅不要彩色模糊背景，改为白色玻璃质感。只改首页、书架、下载页的横幅与首页章节网格，不动解析与下载。

## 改动

| 项 | 做法 |
|---|---|
| 章节格 | 高 58 → 42，数字 17pt → 15pt（`MGFont.section`），圆角 12 → 8，列最小宽 78 → 60，间距 8 → 6 |
| 默认折叠 | 新打开一部漫画时全部分组折叠；只有一个分组时保持展开（否则页面只剩一行标题）。同一部漫画刷新时，新出现的分组也折叠 |
| 折叠的含义 | 折叠只影响显示：「下载全部可见」「全选可见」按当前分类和搜索计算，不再因折叠变成 0；⇧ 连选、框选仍只作用于展开的格子 |
| 横幅统计 | 首页去掉分组数、最新、已下载胶囊；书架横幅去掉「来源 / 书架共」；下载页的进度统计保留（有实际意义） |
| 横幅背景 | 去掉封面模糊与深色渐变；改为 `regularMaterial` + 白色提亮（深色模式为深色玻璃）+ 细描边 + 柔和投影；文字跟随系统前景色；横幅按钮：主按钮用主题强调色，次按钮浅灰底 |

## 约束

- 普通修改（视觉调整）：`1.17.0` → `1.17.1`。
- 相关选择测试按新的折叠含义更新。

## 决策记录

- `visibleChapters` 改为「当前分类 + 搜索」，不受折叠影响；新增 `expandedChapters` 给 ⇧ 连选和框选用。`hiddenSelectedChapterCount` 随之只统计被分类/搜索隐藏的已选章节。
- 默认折叠在 `applyFetchedComic`（新漫画）和恢复上次会话时设置；同一部漫画阶段结果从 1 组变多组时按新漫画处理，否则保留用户展开状态、只折叠新出现的分组。移除视图里「换漫画清空折叠」的旧逻辑。
- `MGHeroBanner` 去掉 `coverURL` 参数；封面描边改为阴影；横幅按钮主色改为主题强调色。书架横幅的「来源」改为一行次要文字。
- 测试：选择测试按新语义更新，新增「新漫画默认折叠 / 单组不折叠」；两个点击章节格的测试先展开分组。

## 结果

- 版本 `1.17.1`；`swift test` 87 项通过（3 项按设计跳过）。
- 快照核对：经典 / 墨与纸横幅为白色玻璃、无统计胶囊；默认折叠；1200 宽每行约 16 格（原约 8 格）。
