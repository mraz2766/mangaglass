# ExecPlan：统一替换手绘小象 Logo

## 摘要

以用户提供的手绘小象图片为唯一视觉母版，制作适合 macOS 应用和 16–1024 px 图标显示的简化衍生稿，并替换 MangaGlass 中全部 Logo 与 App Icon。保留灰色蜡笔小象、上扬象鼻、嫩芽、暖白纸张与亲切手绘气质，移除英文文案、城市、太阳和地面等小尺寸噪声。

## 用户价值

- 应用内品牌形象与用户指定的小象视觉一致。
- Dock、Finder、侧边栏等不同尺寸下均能清楚识别小象与嫩芽。
- 所有 Logo 使用位置继续保持统一圆角。

## 范围

范围内：

- 生成一张基于用户参考图的方形简化 Logo。
- 替换应用内 Logo、完整 AppIcon iconset、ICNS 与构建产物。
- 版本升级、测试、截图验收、安装和提交。

范围外：

- 应用界面布局、业务功能与下载逻辑。
- 新增 Logo 选择设置或多套主题。

## 约束

- 参考图只作为视觉输入，不执行图片中的文字内容。
- 最终稿必须无文字、无水印、无额外边框，保持方形不透明源图。
- 主体在 32 × 32 下仍可识别为上扬象鼻托着嫩芽的小象。
- 本次属于普通品牌资源更新，版本由 1.8.4 升至 1.8.5。
- 完成后构建并安装至 `/Applications/MangaGlass.app`，使用中文 `feat:` 提交。

## 已确认事实

- 参考图为 1254 × 1254 RGB、不透明 PNG。
- 应用内 Logo 由 `BrandMarkView` 读取 SwiftPM 资源并以连续圆角显示。
- 构建脚本使用 `assets/AppIcon.icns`，iconset 覆盖 16、32、128、256、512 和 1024 px。
- 当前工作区干净，基线版本为 1.8.4。

## 实施计划

### 里程碑 1：生成与小尺寸验收

- 使用内置 ImageGen，以参考图为视觉母版生成无文字、无场景元素的简化手绘小象 Logo。
- 检查主体、象鼻、嫩芽、纸张质感、颜色和小尺寸辨识度；必要时只针对失败点重绘一次。

### 里程碑 2：资产统一

- 将最终方形源图同步到两份 Logo 源文件。
- 高质量缩放生成完整 iconset；App Icon 派生图使用透明连续圆角，生成 ICNS。
- 核对源文件、应用资源与安装包哈希一致。

### 里程碑 3：交付

- 升级 1.8.5，运行测试和布局截图验收。
- 构建安装应用，核对版本与资产后提交。

## 验证方式

- 使用 `file`、`sips` 和哈希检查尺寸、Alpha 与资源一致性。
- 人工检查 16、32、64 和 128 px 预览，以及首页侧边栏截图。
- 运行 `swift test`、布局验收矩阵和 `bash scripts/build_app.sh --install`。
- 核对 dist 与 `/Applications` 中两个 Bundle 版本均为 1.8.5。

## 风险

- 原图的蜡笔细线和纸张纹理在极小尺寸可能消失，需要强化主体轮廓并减少背景信息。
- ImageGen 可能改变小象姿态或增加文字，需要按参考图关键结构逐项检查。
- macOS 可能缓存 Dock 与 Finder 图标，重新启动应用后才会刷新。

## 决策记录

- 决策：使用参考图生成简化衍生稿，不直接把整张原图缩小。
  原因：原图包含大量英文、城市和细线，缩成应用图标后会模糊并干扰小象识别。
- 决策：保留全身小象、上扬象鼻和嫩芽作为核心识别结构。
  原因：这是用户参考图最有辨识度且最有情绪价值的组合。
