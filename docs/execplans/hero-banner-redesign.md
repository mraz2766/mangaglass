# ExecPlan：「沉浸封面」风格全站改版

## 摘要

用户在三个方向中选定 A（沉浸封面），但不接受草图里的固定配色（酒红横幅 + 珊瑚色按钮），要求沿用 A 的设计风格并把其他页面一起改。只改视觉与交互，不改下载/解析逻辑。

## 配色决策

- 横幅背景 = 当前漫画封面的大半径模糊 + 自上而下的深色渐变（保证白字可读）。颜色来自漫画本身，不写死任何色值。
- 无封面时用中性深灰渐变，不用主题强调色铺满。
- 横幅内按钮：主按钮白底黑字胶囊，次按钮半透明白胶囊；不依赖主题色，任何封面上都协调。
- 横幅以外沿用当前主题（经典 / 墨与纸 / 石墨）。

## 设计语言

| 元素 | 规范 |
|---|---|
| 横幅 | 圆角 16，高约 210；左侧大封面（白描边 + 投影），28pt 标题，信息行，统计胶囊，右下操作胶囊 |
| 章节格 | 圆角 12、高 58；数字 17pt 半粗 + 单位 10pt；无复选框；选中 = 反色块 + 左上勾；已下载 = 右上绿点 |
| 分组标题 | 无灰底；15pt 标题 + 已选计数 + 文字按钮「全选本组 / 取消全选」 |
| 输入框/搜索 | 胶囊形 |
| 卡片 | 设置页每组一张圆角卡片，取代分隔线 |

## 范围

- 新增 `UI/HeroBanner.swift`（横幅、胶囊按钮、章节格）。
- 首页解析后：横幅（「选最新 10 话」「下载全部可见」）、分类胶囊、新章节格、新分组标题、已下载标记（检查下载目录）。
- 首页空状态：胶囊输入框、更大的最近封面。
- 下载页：横幅（当前漫画模糊封面 + 大号百分比、速度、剩余时间、控制按钮）。
- 书架：横幅（最近打开的漫画 +「继续」），下方封面网格。
- 设置：分组卡片化。
- `MainViewModel`：`selectLatest(_:)`；`DownloadOutputLayout`：已下载章节检测。
- 快照覆盖三主题 × 浅/深。

## 约束

- 显著 UI 改版：`1.14.1` → `1.15.0`。
- 已下载检测只读文件系统，后台线程执行，不发网络请求。

## 决策记录

- 横幅背景放在 `.background` 而非 ZStack 子视图：填充缩放的封面会撑大布局，把文字和按钮挤出可见区域（首次渲染发现并修复）。
- 「下载全部可见」= 选中当前分类下全部章节后走既有的加入队列流程（含已有文件确认），不新增下载路径。
- 「选最新 10 话」取当前可见分组中章节最多的一组，避免「卷」「话」编号混排。
- 统计胶囊改为「标签在前、数值在后」（「第 1 卷 40」比「40 第 1 卷」好读）。
- 一分钟内的时间显示「刚刚」；空首页无内容时隐藏清除按钮。

## 结果

- 版本 `1.15.0`；`swift test` 69 项通过（3 项按设计跳过）。
- 快照核对：首页（空/已解析）、下载、书架、设置 × 三主题 × 浅/深；README 截图用生成的示例封面重新渲染，可见真实模糊背景效果。
- 未实测：真实漫画封面在不同色调下的横幅可读性（已加 18%→58% 深色渐变兜底）。
