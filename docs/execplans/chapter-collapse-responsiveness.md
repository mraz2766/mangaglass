# ExecPlan：章节交互与下载队列可靠性修复

## 摘要与用户价值

修复“番外篇／卷／话”分组标题点击不稳定、展开收起卡顿。分组标题获得稳定的大命中区域；章节拖拽只在章节网格内启动；折叠立即完成，仅保留箭头的轻量状态反馈。

补齐“加入队列”的即时反馈，并把下载队列改为后台原子保存的紧凑快照。正常退出和异常终止后，未完成任务均可在下次启动恢复，运行中任务恢复为待下载，不重复已完成任务。

解除下载器高频进度和整个应用视图树之间的刷新耦合，使首页章节选择不再被后台下载进度反复触发重算；压缩队列页在每次刷新时的重复统计工作。

## 视觉与交互方向

- 视觉原则：维持当前克制、无额外卡片的章节区，整行标题表达单一的展开／收起动作。
- 内容结构：标题名称、选择计数和剩余空白属于折叠按钮；右侧三态按钮只负责本组选择。
- 交互原则：点击与轻微鼠标移动优先视为标题操作；章节拖拽不覆盖分组标题；不动画化网格高度或布局。
- 入队反馈：按钮保持固定尺寸，在原位切换为勾选图标和“已加入 N 话”；实际新增后清除首页章节选择。没有新增时显示“已在队列中”，避免误认为点击无效。

## 范围与约束

- 由于新增下载队列持久化结构和恢复路径，按状态管理改造处理，版本 1.5.2 → 1.6.0。
- 保留章节单击、Command／Shift、拖拽选择、分组选择、吸顶标题和选择状态。
- 保持 `DownloadTaskItem` 运行时模型和下载网络策略；旧 `UserDefaults` 队列可读取并迁移。
- 完成后构建安装 `/Applications/MangaGlass.app`，核对版本并中文 `feat:` 提交。

## 已确认原因

- 整个 `ScrollView` 挂载了 6 pt 起步的拖拽手势，覆盖分组标题；实际用约 9 pt 轻微移动复现点击丢失。
- 折叠使用 `withAnimation` 移除完整 `LazyVGrid`，每个章节的 `GeometryReader` 同时持续回写坐标状态，引发重复布局。
- 当前只有箭头和名称可点击，计数及行内空白不属于折叠按钮。
- 队列使用 `[DownloadTaskItem]` 直接编码，每条任务都重复包含 `ComicInfo` 及其全部章节；大量章节时数据接近平方级膨胀。
- 队列编码和 `UserDefaults` 写入由主线程上的 Combine sink 执行，下载状态频繁变化时会与界面交互争用主线程。
- 现有恢复会把 `.running` 转成 `.queued`，但缺少原子文件快照和退出前同步检查点。
- `MainViewModel` 当前把 `DownloadCoordinator.objectWillChange` 原样转发；所有观察 `MainViewModel` 的页面会随单页下载进度一起刷新，首页的大章节网格也被波及。

## 实施计划

1. 将坐标缓存改为不触发视图刷新的引用存储，只在拖拽计算中读取。
2. 把拖拽手势从整个滚动区移动到每个展开的章节网格，并提高意图阈值。
3. 重构分组标题命中区域，去掉网格布局动画，只为箭头提供快速旋转反馈。
4. 让入队逻辑返回实际新增数量，按钮在不改变布局的前提下显示成功或重复反馈。
5. 引入版本化紧凑队列快照：漫画去重、后台串行写、原子替换、旧数据迁移和退出前同步检查点。
6. 移除下载器到整个 `MainViewModel` 的无差别刷新转发；队列页与侧栏直接观察下载器，首页不订阅下载进度。
7. 缓存队列页单次渲染所需的筛选和计数结果，避免同一轮重复遍历任务数组。
8. 增加快照往返、旧状态恢复和入队计数测试；运行逻辑测试和快照测试，并实机验证点击与恢复提示。

## 决策记录

- 决策：持久队列写入 Application Support 的版本化 JSON 文件，`UserDefaults` 只作为旧版本迁移来源。
  原因：原子文件可避免半写入，紧凑结构避免漫画元数据随任务数重复，后台串行队列保证保存顺序。
- 决策：正常退出前同步写入当前快照，平时状态变化异步保存。
  原因：日常下载不阻塞界面，同时保证系统正常终止时最后状态落盘；异常终止至少保留最近一次完整原子快照。
- 决策：恢复后仍由现有弹窗让用户选择继续下载或打开队列。
  原因：避免重启应用后在用户不知情时立刻发起大量网络请求。
- 决策：只有实际新增任务时清除当前漫画的全部选择。
  原因：符合用户指定的默认行为，同时避免“已在队列中”的重复操作被误报为一次新增。
- 决策：需要实时显示下载进度的队列页和侧栏直接观察 `DownloadCoordinator`，不再让 `MainViewModel` 广播下载器的全部变化。
  原因：首页、历史和设置无需按下载页级进度刷新；缩小观察范围比单纯缩短动画更能消除卡顿根因。
