# ExecPlan：MangaGlass 小象 IP Logo 全量替换

## 摘要

参考 `ip-as-logo` 规则，将现有细节较多、缩小时辨识度不足的水彩小象重做为简洁的小象品牌符号。先生成 A 开卷小象、B 下载小象、C 印章小象各两个独立候选，经用户选定后统一替换应用内 Logo、资源 Logo、App Icon 全尺寸和安装包。

## 用户价值

- 小象在侧栏 28 pt、Dock、Finder 和通知等小尺寸场景中仍能清楚识别。
- 应用内品牌图与系统 App Icon 使用同一视觉来源，避免当前多份资产不一致。
- 保留 MangaGlass 温和、简洁的气质，减少插画细节和空白。

## 范围

范围内：

- 生成六张独立方形候选：`A1`、`A2`、`B1`、`B2`、`C1`、`C2`。
- 检查主体比例、三种语义色、不透明背景、方形画布及 32 × 32 可读性。
- 用户选定后更新 `assets/logo.png` 与 SwiftPM 资源。
- 从最终稿生成完整 `AppIcon.iconset` 和 `assets/AppIcon.icns`。
- 检查所有 Logo 引用，构建安装并核对应用内、Finder 和 Dock 使用同一资产。

范围外：

- 不修改应用现有主题色和业务界面配色。
- 不改变导航、下载和队列功能。
- 不把六个候选合成为一张源文件或使用带圆角的生成画布。

## 约束

- 生成图必须是独立的 1:1 不透明方形原图；应用显示层继续负责圆角裁切。
- 每张默认使用两个小象基础色和一个纯色背景，保持粗圆轮廓、低复杂度和轻微连续渐变。
- 最终资产需兼容 macOS 13。
- 本次属于普通品牌资产修改，版本 `1.8.2` → `1.8.3`。
- 完成后运行 `bash scripts/build_app.sh --install`，替换 `/Applications/MangaGlass.app` 并以中文 `feat:` 提交。

## 已确认事实

- 当前两份 Logo 均为 1254 × 1254、不透明 PNG，主体占画布较小且包含水彩纹理和大量线条。
- 应用内通过 `BrandMarkView` 加载 SwiftPM 的 `logo.png`，显示时使用连续圆角裁切。
- 构建脚本将 `assets/AppIcon.icns` 写入 App Bundle；现有 iconset 覆盖 16、32、128、256、512 和 1024 像素。
- 用户已接受全部三个方向，按 A、B、C 每个方向两个候选生成。

## 实施计划

### 里程碑 1：独立候选

- 生成六张独立方形候选并保存原始文件。
- 为每张记录方向、构图、颜色、尺寸、不透明度和约束偏差。
- 制作仅用于评审的候选预览，向用户展示并等待最终选择。

### 里程碑 2：资产统一

- 将选定稿同步为应用内 Logo 源文件。
- 使用高质量缩放生成完整 iconset，并用 `iconutil` 生成 ICNS。
- 检查 16、32 和 64 像素下的轮廓与五官清晰度。

### 里程碑 3：构建交付

- 更新版本至 1.8.3，运行自动测试和构建安装。
- 核对 dist 与 `/Applications` 版本及资源一致性后提交。

## 验证方式

- 使用 `file`、`sips` 和图像检查脚本核对尺寸、Alpha 与资产哈希。
- 生成 32 × 32 和 64 × 64 预览并人工检查识别度。
- 运行 `swift test` 与 `bash scripts/build_app.sh --install`。
- 核对两份 Logo 哈希一致、ICNS 成功生成、两个 Bundle 版本均为 1.8.3。

## 风险

- 图像模型可能产生额外颜色、纹理、外框或过度立体感，需要逐张检查并针对性重试。
- 小尺寸缩放可能吞掉眼睛或象鼻间隙，最终稿需以 16–32 像素实际预览判断。
- macOS 会缓存 Dock 和 Finder 图标，安装后可能需要重新启动应用才能看到新图。

## 决策记录

- 决策：六个候选均保存为独立原图，不要求模型生成六宫格。
  原因：保持每张候选的原始分辨率，避免网格裁切和候选间视觉污染。
- 决策：最终方形源图不预先裁圆角。
  原因：App Icon 和应用内控件应分别由系统或 SwiftUI 显示层处理圆角。
- 决策：第一轮六个候选全部淘汰，第二轮取消书页、下载流线和印章面罩等主导隐喻，改为“物种识别优先”的六个小象形态。
  原因：第一轮方耳、面罩和夸张卷鼻破坏了小象的典型结构，用户明确反馈整体不像象。
- 决策：用户选定第二轮 D3 作为最终稿；方形原图作为品牌源文件，App Icon 派生图使用透明连续圆角。
  原因：D3 的额头、长鼻、双耳、低矮身体和柱状腿最像小象；源图保持可复用，部署图同时满足所有 Logo 使用位置统一圆角的既有要求。
