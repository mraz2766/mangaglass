# ExecPlan：去掉侧栏 Logo、统一标题栏色差、修复侧栏点击

## 摘要

用户反馈三件事：应用内侧栏顶部的 Logo 不显示，要求去掉这个设计；窗口标题栏和下方界面颜色不一致；重启后侧栏点击无反应（「卡死」）。只改窗口外观与侧栏，不动下载、解析逻辑。

## 用户价值

- 侧栏顶部不再出现空白/坏图的 Logo 位。
- 标题栏与侧栏、内容区同色，窗口看起来是一整块。
- 侧栏按钮点击、悬停稳定可用。

## 方案

| 项 | 做法 |
|---|---|
| Logo | 删除侧栏 `BrandMarkView` 及其定义（Dock 图标不受影响） |
| 标题栏 | `fullSizeContentView` + `titlebarAppearsTransparent`，侧栏与内容背景延伸到标题栏下；交通灯落在侧栏顶部，侧栏顶部留出标题栏高度 |
| 侧栏按钮 | 精简结构：去掉自定义 ButtonStyle 内的 hover 包装与 `matchedGeometryEffect`，改用与章节格相同的普通 Button + 外层 `onHover`；选中底色直接画在按钮内 |
| 侧栏宽度 | 64 → 72，给交通灯留出余量 |

## 约束

- 普通修改：`1.15.1` → `1.15.2`。
- 窗口只写有变化的属性（保持 1.15.1 修复的约束）。
- 构建并替换 `/Applications/MangaGlass.app`，中文 `feat:` 提交。

## 决策记录

- 侧栏点击问题在 NSHostingView 测试中无法复现，真实窗口里悬停/按下事件都未到达；先用更简单的按钮结构 + 新窗口样式重建，再用真实鼠标点击验证。
- 重建后真实点击仍无效，定位到真正原因：横幅背景的封面 `scaledToFill` + `scaleEffect(1.2)` 溢出横幅，`clipShape` 只裁剪显示、不裁剪点击，溢出部分盖住了侧栏。之前的测试没有加载真实封面，所以复现不了。修复：横幅背景 `allowsHitTesting(false)`，横幅与 `MGBookCover` 加 `contentShape`。
- 侧栏内容留在安全区内（顶部 12pt 间距），只有背景延伸到透明标题栏下，交通灯不被遮挡；原「标题栏不透明」测试改为断言新行为。
